# ⚔️ YBA Discord ELO / Ranked Bot (Glicko-2)

Дискорд-бот для соревновательной лиги 1v1 в **Roblox Your Bizarre Adventure (YBA)**.
Использует математическую модель **Glicko-2** (по аналогии с Lichess):
- Стартовый рейтинг: **1500 ELO**.
- Быстрая калибровка первых матчей: **$\pm 162$ очка** за матч.
- Постепенная стабилизация очков при наборе дистанции (~$\pm 10–25$).
- Шахматные разряды и титулы (**Мастер**, **Гроссмейстер**, **Топ-10**, **Чемпион**).
- Автоматическая синхронизация ролей в Discord.
- Отдельный интерфейс для **Респов** (судей) с подтверждением и защитой от ошибок (откат матча).
- Очередь поиска соперников 1 на 1 (`/queue`).
- Сезоны и Soft Reset.
- Ротация логов и автоматическая защита от переполнения диска резервными копиями.

## 🚀 Деплой в Production (Docker Compose) — Рекомендуется

Самый надёжный и быстрый способ запуска бота на VDS/сервере с изоляцией, сохранением данных и автоматическим перезапуском:

### 1. Клонирование и настройка
```bash
git clone <repo_url> yba-bot
cd yba-bot
cp .env.example .env
nano .env  # Укажите DISCORD_TOKEN и GUILD_ID
```

### 2. Запуск контейнера
```bash
docker compose up -d --build
```

### 3. Просмотр логов в реальном времени
```bash
docker compose logs -f bot
```

### 4. Остановка / Перезапуск
```bash
docker compose restart
docker compose down
```
> [!NOTE]
> Все данные базы данных SQLite и бэкапы автоматически сохраняются на хосте в папке `./data`, а логи — в `./logs`.

## 🛠️ Запуск без Docker (Systemd на Linux)

Если вы запускаете бота напрямую на хосте (Ubuntu / Debian):

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск тестов
```bash
python -m unittest discover tests
```

### 3. Настройка Systemd службы
```bash
sudo cp yba-bot.service.example /etc/systemd/system/yba-bot.service
sudo nano /etc/systemd/system/yba-bot.service  # Отредактируйте пути и пользователя
sudo systemctl daemon-reload
sudo systemctl enable --now yba-bot
```

### 4. Просмотр статуса и логов
```bash
sudo systemctl status yba-bot
journalctl -u yba-bot -f
```

## 🎮 Команды бота

### Для всех игроков:
* `/link <roblox_username>` — привязать свой ник в Роблоксе.
* `/profile [user]` — карточка игрока (ELO, ранг, пиковый рейтинг, винрейт, стрик, статус калибровки).
* `/leaderboard [страница]` — таблица лидеров сервера по рейтингу.
* `/ranks` — список всех доступных рангов и диапазонов очков.
* `/queue join` — встать в очередь поиска соперника 1v1.
* `/queue leave` — выйти из очереди.
* `/queue status` — список игроков, ищущих соперника прямо сейчас.

### Для Респов (судей):
* `/match report winner:@Игрок loser:@Игрок [proof]` — внести результат дуэли. Бот мгновенно пересчитает очки, обновит роли в Discord и выдаст красивую карточку результата.
* `/match undo <match_id>` — аннулировать матч и вернуть рейтинги назад (если респ ошибся).
* `/match history [user]` — история последних матчей.

### Для Администраторов:
* `/season info` — информация о текущем сезоне.
* `/season reset <название> confirm:True` — безопасный сброс сезона (Soft Reset) с автоматическим бэкапом базы данных.
* `/sync_roles` — принудительно обновить Discord-роли всем игрокам согласно их ELO.
* `/backup` — создать атомарную резервную копию базы данных без остановки бота.
* `/set_elo user:@Игрок rating:1650 reason:...` — экстренная ручная корректировка рейтинга игрока администратором.
* `/sync_commands` — принудительно синхронизировать слэш-команды бота для сервера.

## 🏆 Ранговая система

| Значок | Ранг | Диапазон ELO | Описание |
|---|---|---|---|
| 🟤 | **Unranked / Калибровка** | Первые 5–10 матчей | Быстрая калибровка с плашкой `?` к рейтингу |
| 🥉 | **Bronze** | < 1300 ELO | Начальный ранг |
| 🥈 | **Silver** | 1300 – 1499 ELO | Базовый ранг |
| 🥇 | **Gold** | 1500 – 1699 ELO | Средний уровень (старт с 1500) |
| 💎 | **Diamond** | 1700 – 1849 ELO | Опытные дуэлянты |
| 🔮 | **Master** | 1850 – 1999 ELO | Топ 3–5% лучших игроков сервера |
| 👑 | **Grandmaster** | 2000+ ELO | Пик ладдера (топ 1–3 игрока) |
| 🏆 | **Top 10** | Топ-10 сезона | Эксклюзивная роль для 10 лучших игроков |
